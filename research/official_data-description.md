## Files

*   **sample_submission.csv** - a sample submission file in the correct format

Submit a single CSV file with one row per placed unit square:

| Column | Description |
|--------|-------------|
| `id` | Row identifier (0 … number of rows − 1) |
| `n` | Which puzzle (1–1,000) this square belongs to |
| `square_id` | Index of this unit square within the puzzle (0 to n-1) |
| `x` | x-coordinate of the square's center |
| `y` | y-coordinate of the square's center |
| `angle` | Rotation angle in radians |
