# Squares in Squares

Competition optimization workspace for [Kaggle Squares in Squares](https://www.kaggle.com/competitions/squares-in-squares). Goal: the highest achievable leaderboard position while following the rules. See [GOAL.md](GOAL.md) for authorization, compute limits and continuation notes.

For each n=1..1000, place n non-overlapping unit squares inside the smallest square. Minimize `sum(L_n / sqrt(n) - 1)`. Angles are radians. Complete submissions contain 500,500 rows. Exact decimal coordinates matter: float round trips can invalidate touching packings.

The latest accepted submission, **57584666**, scored **22.3047579593**; its observed rank was20/505 on2026-10-24. Continued search has certified a stronger unsubmitted portfolio at **22.3023255821**. The user now requires **both validated transport scores strictly below22.3** before another submission. The hourly runner is stopped. Read [research/STATUS.md](research/STATUS.md) for current experiments and [research/submission_schedule.md](research/submission_schedule.md) for the enforced authorization policy.

## Environment

Python 3.12 and Node.js 24 are available. The project uses a local virtual environment:

```bash
cd /workspace/squares_in_squares
UV_CACHE_DIR=/workspace/.cache/uv uv venv --system-site-packages --allow-existing .venv
UV_CACHE_DIR=/workspace/.cache/uv uv pip install --python .venv/bin/python -r requirements.txt
```

The optional Torch search backend is pinned separately in requirements-search.txt. The additional MIT-licensed Rust fq optimizer builds with `cargo build --release --locked --manifest-path vendor/fq/Cargo.toml --bin fq`; see research/fq_active_pilot.md for its tested toolchain and geometry checks. The official Kaggle GPU environment supplies CUDA Torch/CuPy for remote searches. Each cloud task is already isolated; use this checkout without creating a worktree unless explicitly requested.

## Reproduce and certify a baseline

```bash
mkdir -p artifacts
node vendor/unitSquares/tools/make-submission.mjs artifacts/baseline.csv
.venv/bin/python scripts/validate_submission.py artifacts/baseline.csv --workers 2 --report artifacts/baseline-validation.json
.venv/bin/python scripts/score_official.py artifacts/baseline.csv --workers 2
```

The vendored MIT source and public coordinate provenance are documented in [vendor/SOURCES.md](vendor/SOURCES.md). The original baseline score is 22.37200587895322. Validation checks every case, not just the aggregate score, because the official metric assigns grid penalties to invalid puzzles instead of rejecting the entire CSV.

The merger preserves coordinate strings and admits only independently certified improvements. Artifact files are ignored by Git but retained in the workspace.

## Search and verification

Experiments include rigid envelope optimization, sequential contact LP, neighbor transfer, batched Torch perturbation/relaxation, and independent MILP upright refill. See each script's `--help`. `scripts/build_gpu_job.py` packages selected seed puzzles and a bounded search configuration as a private Kaggle job; it embeds no credential. Search candidates must be merged and certified before submission.

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/kaggle_cli.py quota --format json
.venv/bin/python scripts/kaggle_cli.py kernels status sos54352/squares-search-pilot
```

The CLI wrapper uses a runtime `KAGGLE_API_TOKEN` or a private file named by `KAGGLE_TOKEN_FILE`. Do not commit credentials. It supports the session's protected temporary credential file outside the checkout. Kaggle's authenticated compatibility API is the default; set `KAGGLE_USE_WWW_API=0` for the standard API hostname.

Only submit when both validated scores are strictly below22.3 and the file hash matches successful raw and numeric-roundtrip official validation reports. Check current submission history, wait at least an hour between accepted submissions, require a strictly better score, and stay within 10 submissions/day. Keep receipts and actual scores in artifacts/submissions/. Report leaderboard gains only after Kaggle returns a scored result.
